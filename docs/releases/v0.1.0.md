# v0.1.0 — Initial release

This is the first public release of `@jalau-labs/jala-u-ds4-web-components`, a small, dependency-free library of reusable web components built with plain HTML, CSS, and JavaScript.

## Highlights

- **Card** component with three visual variants (`default`, `outlined`, `elevated`), optional subtitle, body, and actions.
- **Tooltip** component with four placement positions (`top`, `right`, `bottom`, `left`), keyboard support, ARIA wiring, and portal rendering.
- **Design tokens** for colors, typography, spacing, radii, shadows, transitions, and z-index layers, exposed with low specificity via `:where(:root)`.
- **Dual distribution** as ESM and UMD bundles, plus an aggregated stylesheet.
- **Full test coverage** with Vitest and jsdom. 49 tests passing, 98% combined statement coverage.
- **CI/CD** on GitHub Actions and GitLab CI, with Dependabot for automated dependency updates.

## Installation

```bash
npm install @jalau-labs/jala-u-ds4-web-components
```

## Usage

```js
import { Card, Tooltip } from '@jalau-labs/jala-u-ds4-web-components';

const card = new Card({
  title: 'Weekly summary',
  body: 'All tasks completed successfully.',
  variant: 'elevated',
});

document.querySelector('#app').appendChild(card.render());

const tooltip = new Tooltip({ text: 'Additional context' });
tooltip.attach(document.querySelector('#help-button'));
```
